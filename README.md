# Episode · AI Health Navigator

从身体出现异常，到见到医生之前的**连续健康导航**。把一次「不舒服」整理成一条有始有终、可持续更新的健康事件。

> We don't replace the doctor. We manage the journey before you see one.

## Demo（静态站点）

`dist/` 是一个纯静态单页应用（无构建、无外部依赖），直接用浏览器打开 `dist/index.html` 即可体验。

页面流程：

1. 首页 / 产品定位
2. AI 结构化问询（开始一次 Health Episode）
3. Episode 时间线 / 症状趋势 / 下一步行动分层
4. Doctor Handoff 就医摘要

## 免责声明

本项目为**产品概念 Demo**，所有人物、症状与数据均为虚构，不提供、也不替代专业医疗建议。
